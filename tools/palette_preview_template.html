Palette Bench

Each tileset table picks one of 8 colour slots for every tile. The base set picks the 4 colours in each slot. Swap the base set and the same tiles recolour; that is all a variant is. Click any swatch, or any pixel in a sheet, to edit that colour.

Generated from source by tools/palette_preview.py. Edits live only in this browser until you paste the copied asm into
    custom_functions/func_enhancedcolor.asm (Enhanced base sets) or data/gfx/cgb_palettes.asm (Regular GBC rows) and re-run
    the script. Regular GBC rows are what the game uses with Enhanced Colors off: one palette for the whole map, never gamma-corrected.
    "ENH GAMMA option on" applies GBCGamma to Enhanced sets (colour matrix, then the gamma table; near-blacks with every channel
    under 4 are left alone). "Real GBC screen" is an approximation of the unlit GBC LCD (byuu's colour-correction matrix, as used by higan and
    several other emulators), so the final check is still real hardware. Tiles $60 and up in tilesets other than DORM fall back to GRAY, as
    MakeOverworldBGMapAttributes does.
