Palette Bench

Each tileset table picks one of 8 colour slots for every tile. The base set picks the 4 colours in each slot. Swap the base set and the same tiles recolour; that is all a variant is.

Hover a tile to see its ID and slot. Click a slot to highlight the tiles that use it.

Generated from source by tools/palette_preview.py. Colours are the raw source values; in game they also pass through GBCGamma, so hardware shows them a little darker and flatter. Tiles $60 and up in tilesets other than DORM fall back to GRAY, as MakeOverworldBGMapAttributes does.
